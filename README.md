# Vijay Kumar Saw - Developer Portfolio

A modern, responsive, and animated personal developer portfolio built with HTML5, CSS3, and JavaScript.

## 🚀 Live Demo & Preview
Simply open `index.html` in any modern web browser or serve it using VS Code Live Server.

## ✨ Features & Enhancements
- **Refined Dark Theme & Glassmorphism**: Slate/zinc dark palette with glowing cyan and violet gradients and frosted glass backdrop blur.
- **Dynamic Typewriter Effect**: Powered by Typed.js cycling through key developer roles.
- **Scroll Reveal Animations**: Smooth scroll entrance animations utilizing the native `IntersectionObserver` API.
- **Interactive 3D Tilt**: Parallax tilt on profile and project cards using `vanilla-tilt`.
- **Animated Skill Progress Bars**: Technical proficiency meters that fill up smoothly when scrolled into view.
- **Project Showcase & Category Filters**: Tabbed filtering for Websites and Games with 1-click live demo links:
  - 🌐 [School Website (SBPS)](https://kumarvijay09.github.io/schoolWebsite/)
  - 🎮 [Rock Paper Scissors Game](https://kumarvijay09.github.io/RockPaperScissor/)
  - ❌ [Tic Tac Toe Game](https://kumarvijay09.github.io/TicTacToe/)
- **Direct Resume Integration**: 1-click download button linked directly to `assets/docs/Vijay_Resume.pdf`.
- **Interactive Contact & Copy Tools**: Copy-to-clipboard email utility and contact form with live toast feedback.
- **Reading Progress Bar & ScrollSpy**: Top progress bar and automatic active navigation highlighting.

## 🛠️ Built With
- **HTML5**: Semantic tags, accessibility attributes, and responsive viewport.
- **CSS3**: CSS Variables, Flexbox, CSS Grid, Keyframe animations, Backdrop filters.
- **JavaScript (ES6+)**: Scroll events, DOM manipulation, Clipboard API, IntersectionObserver.
- **Libraries & Icons**:
  - [Typed.js](https://github.com/mattboldt/typed.js/)
  - [Vanilla Tilt](https://micku7zu.github.io/vanilla-tilt.js/)
  - [Font Awesome 6](https://fontawesome.com/)
  - [Devicon](https://devicon.dev/)
  - [Google Fonts](https://fonts.google.com/) (Plus Jakarta Sans & Fira Code)
